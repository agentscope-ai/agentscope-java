# 自动化与渠道

在手动路径验证成功后，再让定时或外部事件触发同一类工作。

## 自动化

创建 Automation，选择触发方式和目标 Agent、Team 或已支持的编排入口。先手动运行一次，检查输入、目标资源权限、执行记录和交付物，再启用周期触发。

配置中写明任务范围、输出位置和重复执行的预期行为。遇到失败先定位对应 Run / Task，再决定补跑；避免同时创建多个重复周期任务。

## 渠道

在 Channels 中配置平台连接与 Agent 关联。渠道凭据、回调 URL、消息路由和用户身份绑定分别承担不同职责。远程回调需要可达的 HTTPS 地址；OAuth 回调还需要正确的公开服务地址。

先发送一条测试消息，检查它产生的工作、权限判断和回复是否回到原渠道。涉及用户身份的工作，应完成身份配对；Profile 可管理自己的连接和订阅。

不同渠道支持的消息格式与能力有差异，以该渠道配置页面和实际验证为准。不要把所有渠道都当作支持相同事件的通用 Webhook。

## 运维检查

检查 Scheduler 是否健康、控制面连接是否正常、相关密钥是否有效，以及第三方是否能访问回调路径。轮换外部凭据后重新验证收发链路。
