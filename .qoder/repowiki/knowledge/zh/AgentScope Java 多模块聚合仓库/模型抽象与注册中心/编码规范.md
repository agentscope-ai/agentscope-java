- 所有 public 参数在入口处使用 `Objects.requireNonNull` 进行防御性校验，空值抛出 `IllegalArgumentException`。
- 可选能力通过接口 default 方法暴露（如 `supportsNativeStructuredOutput`、`getContextWindowSize`），子类仅在需要时覆盖。
- 可变共享状态使用并发安全容器：`ConcurrentHashMap` 存命名模型与缓存，`CopyOnWriteArrayList` 存用户工厂，SPI 列表用 volatile 引用 + 双重检查锁初始化。
- 对外错误信息通过集中构建器（如 `buildNotFoundMessage`）生成包含可用 provider 格式与所需环境变量的诊断文本。
