本模块以三层契约串联：
- 顶层 `Model` 接口 + `ChatModelBase` 抽象基类定义统一的流式聊天语义，并通过 `ModelRegistry` + SPI (`spi.ModelProvider`) 按 modelId 解析实例；
- 中间层 `transport/HttpTransport` 与 `transport/WebSocketTransport` 分别屏蔽 JDK/OkHttp 的 HTTP(SSE) 与 WebSocket 差异，由 `JdkHttpTransport`/`OkHttpTransport` 与 `JdkWebSocketTransport`/`OkHttpWebSocketTransport` 提供实现；
- 最底层各 Provider 的具体模型实现仅依赖 `Model` 契约与 transport 接口，通过 `ModelCreationContext` 注入所选 transport 完成请求编排。
三者共同构成“协议无关的模型调用”边界，上层 Agent 只面向 `Model` 编程，不感知 HTTP/WebSocket 或具体厂商 SDK。
