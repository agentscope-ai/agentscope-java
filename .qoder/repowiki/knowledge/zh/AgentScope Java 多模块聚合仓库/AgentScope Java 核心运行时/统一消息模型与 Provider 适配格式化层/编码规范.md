- JSON 多态通过 Jackson 注解声明：Msg 使用 `@JsonTypeInfo(property="role")` + `@JsonSubTypes`，ContentBlock 使用 `@JsonTypeInfo(property="type")` + `@JsonSubTypes`，保持 discriminator 字段名与业务语义一致。
- 所有可构建对象类（Msg、JsonSchema 等）提供静态 `builder()` 工厂方法与内部 Builder 类，Builder 方法链式返回自身，build() 返回不可变实例。
- 非持久化计算属性统一标注 `@Transient` 与 `@JsonIgnore`（如 `hasContentBlocks`、`getTextContent`、`getChatUsage`），避免混入 JSON 序列化。
- Formatter 默认方法提供空实现或委托给无 baseUrl/modelName 的重载版本，Provider 实现按需覆盖带 provider 检测的版本以保持向后兼容。
- 媒体来源通过 `Source` 接口及其 `Base64Source`/`URLSource` 实现解耦，ContentBlock 持有 Source 而非直接内嵌二进制数据。
