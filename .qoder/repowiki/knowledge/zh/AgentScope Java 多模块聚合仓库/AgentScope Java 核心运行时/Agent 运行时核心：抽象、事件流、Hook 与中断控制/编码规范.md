- 事件类型采用「Start/Delta/End」三段式命名（如 `TextBlockStartEvent`/`TextBlockDeltaEvent`/`TextBlockEndEvent`、`ToolCallStartEvent`/`ToolCallDeltaEvent`/`ToolCallEndEvent`），表示一次块级操作的增量推送。
- Hook 统一通过 `<T extends HookEvent> Mono<T> onEvent(T event)` 单方法接收所有事件，并在内部用 switch 模式匹配具体子类，同时通过 `priority()` 返回值决定执行顺序。
- 需要跨调用传递的上下文一律通过 Reactor Context 键常量（如 `CALL_SCOPE_KEY`、`RUNTIME_CONTEXT_KEY`、`SHUTDOWN_REQUEST_ID_KEY`、`AgentEventEmitter.CONTEXT_KEY`）存取，而非共享实例字段，以保证并发安全。
- 对可变状态（hooks 列表、runtimeContextAwareHooks）使用 `CopyOnWriteArrayList`，并在构造时拷贝传入集合以避免外部修改影响。
- 中断信号封装为不可变的 `InterruptContext` 快照（通过 `InterruptControl.toContext()` 生成），在错误处理路径中统一转换为 `InterruptedException` 再交由 `handleInterrupt` 消费。
