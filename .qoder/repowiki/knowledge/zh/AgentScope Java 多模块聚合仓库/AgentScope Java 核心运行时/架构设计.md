本模块以 `io.agentscope.core.agent` 为编排入口，通过以下契约把子模块串联：
- 调用链自上而下依次经过 `middleware` 中间件链 → `hook` Hook 钩子 → `tool.ToolExecutor` 工具执行器 → `model.ChatModelBase` 模型抽象 → `credential` 凭据；所有阶段均通过 `event.AgentEventEmitter` 广播 `AgentEvent*` 事件，供外部订阅。
- `message.Msg`/`ContentBlock` 多态模型与 `formatter.Formatter` 作为跨 agent/tool/model/memory 的通用数据契约，屏蔽各 LLM SDK 差异。
- `tool` 与 `skill` 子系统由 `Toolkit`/`SkillRegistry` 统一注册，被 `ToolExecutor` 反射调用；`subagent` 工具内部又反向创建新的 `Agent` 实例，形成递归调用树。
- `model` 层通过 `spi.ModelProvider` + `ModelRegistry` SPI 发现机制加载具体实现，`transport.HttpTransport/WebSocketTransport` 抽象屏蔽 HTTP/WS 差异，被上层复用。
- 权限引擎、OpenTelemetry 追踪、优雅停机、RAG、中断控制等横切能力以中间件/Hook/Context 形式注入到 agent/tool/model 生命周期中。
整体遵循「接口在上、SPI 发现、事件驱动、中间件/钩子可插拔」的分层装配模式。
