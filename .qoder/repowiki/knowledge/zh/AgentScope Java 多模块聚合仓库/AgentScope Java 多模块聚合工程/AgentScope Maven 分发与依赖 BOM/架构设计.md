本模块由三个纯 POM 子模块组成，职责分层清晰：
- `agentscope-distribution`（packaging=pom）作为顶层分发聚合器，通过 `<modules>` 引入 `agentscope-all` 与 `agentscope-bom`。
- `agentscope-all`（artifactId=agentscope，jar）是“全量”胖包，使用 `maven-shade-plugin` 将 `io.agentscope:agentscope-core` 与所有 `agentscope-extensions-*` 打包进单一可部署 artifact；其依赖全部标记为 `<optional>true</optional>`，以便下游按需裁剪。
- `agentscope-bom`（packaging=pom）是项目内 BOM，在 `<dependencyManagement>` 中列出所有 `io.agentscope:*` 子模块并统一绑定 `${project.version}`，供外部工程以 `<scope>import</scope>` 方式引入。
- `agentscope-dependencies-bom`（独立于 distribution 之外）是面向第三方的外部 BOM，集中声明 OpenTelemetry、OkHttp、Reactor、Jackson、Spring Boot、DashScope/OpenAI/Anthropic/Gemini SDK、Milvus/Qdrant/Elasticsearch、Nacos、Tree-sitter 等所有第三方依赖的版本号，并通过 `flatten-maven-plugin` 以 `bom` 模式生成扁平化 POM 用于发布到 Sonatype Central。
依赖方向单向向下：distribution → all/bom → 各 agentscope-* 子模块；external dependencies-bom 被其他模块通过 import 消费，不反向依赖本项目代码。
