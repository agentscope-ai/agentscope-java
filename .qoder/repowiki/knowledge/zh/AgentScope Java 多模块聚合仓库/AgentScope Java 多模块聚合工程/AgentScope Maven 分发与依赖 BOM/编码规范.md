- 所有对外分发的 POM 均继承自父 `agentscope-parent` 并使用 `${revision}` 统一版本号，避免硬编码版本字符串。
- BOM 类 POM 通过 `<type>pom</type><scope>import</scope>` 的方式导入上游 BOM（如 opentelemetry-bom、reactor-bom、jackson-bom），而非逐条声明版本。
- 第三方依赖在 `agentscope-dependencies-bom` 中以 `<properties>` 集中定义版本号（如 `openai-java.version`、`spring-boot.version`），再由 `<dependencyManagement>` 引用该属性。
- `agentscope-all` 中对每个 `io.agentscope:agentscope-extensions-*` 依赖显式标注 `<optional>true</optional>`，使全量包仅作为可选能力集合而非强制传递依赖。
