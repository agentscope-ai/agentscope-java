顶层 pom.xml 作为聚合器，将 agentscope-core（运行时内核）、agentscope-extensions/*（模型/存储/渠道/Spring Boot Starter 等插件）、agentscope-harness（集成测试与基准）、agentscope-examples/*（参考应用）、agentscope-distribution（发布 BOM/全量包）以及 docs（Jupyter Book 站点）统一纳入同一构建；各子模块通过 Maven 依赖声明耦合到 core 或对应 extension，distribution 的 BOM 集中锁定所有子模块版本，形成「core → extensions/examples/harness」单向依赖树，docs 仅消费源码不反向依赖。
