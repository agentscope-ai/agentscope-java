本模块由两个协作子层构成：
- tool/ 提供工具框架核心（Tool、Toolkit、ToolRegistry、ToolExecutor、反射调用、分组与执行管线）以及内置工具集（file、coding、mcp、subagent）。
- skill/ 提供 SKILL.md + YAML frontmatter 描述的技能注册与发现（SkillRegistry、SkillBox），并通过 SkillToolFactory 把每个 RegisteredSkill 包装成 ToolGroup，再交由 Toolkit 管理。
两者通过以下契约耦合：
- Skill 最终暴露为 ToolGroup，被注入到同一个 ToolRegistry/Toolkit 中，与原生工具共享反射调用与执行流程。
- McpClientManager 位于 tool/ 顶层，作为 MCP 工具的共享客户端管理器，供 McpTool 等使用；Skill 侧不直接持有 MCP 连接。
- ToolExecutionContextProvider 与 DefaultContextStore 为工具与 Skill 中间件（DynamicSkillMiddleware、SkillFilter）共享的上下文载体。
- 启动时由外部组装器创建 Toolkit，先注册内置工具，再扫描 SkillRepository 并注册 SkillToolGroup，从而形成“工具 + 技能”的统一能力视图。
