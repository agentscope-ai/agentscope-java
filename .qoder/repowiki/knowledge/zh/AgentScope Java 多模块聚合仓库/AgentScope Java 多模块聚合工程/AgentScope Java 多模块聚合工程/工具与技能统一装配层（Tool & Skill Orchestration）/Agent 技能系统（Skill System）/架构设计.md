模块围绕「技能即 Markdown 文档 + 资源」的模型组织，分层如下：
- 数据层：`AgentSkill` 为不可变值对象（含 name/description/source/originDir/resources），配合 `Builder` 与 `@Deprecated` 标记；`RegisteredSkill` 承载运行时元信息（激活态、tool group 名）。
- 注册与生命周期：`SkillRegistry` 是纯并发存储（ConcurrentHashMap），仅负责 skillId→AgentSkill 与 RegisteredSkill 映射；`SkillBox` 是对外门面，聚合 registry、`AgentSkillPromptProvider`（生成系统提示）、`SkillToolFactory`（创建 load_skill_through_path 工具），并提供 fluent `registration()` 构建器把 skill 与 toolObject/AgentTool/MCP/SubAgent 绑定到 Toolkit 的独立 ToolGroup。
- 动态装配：`DynamicSkillMiddleware` 实现 `MiddlewareBase`，在每次 `onSystemPrompt` 时遍历注入的 `AgentSkillRepository` 列表（低优先级在前、同名覆盖），通过 `filterVisible(ctx)` 钩子做运行时可见性裁剪，计算内容级 SHA-256 签名短路重建，并维护稳定的 workDir 避免每轮 mkdtemp。
- 仓库抽象：`repository/AgentSkillRepository` 接口定义 CRUD 与 source 标识，`FileSystemSkillRepository` 基于 baseDir 下每个子目录的 SKILL.md 解析，带 mtime+size 快照缓存与 lazy 模式（只预读 SKILL.md，支持文件通过 originDir 延迟读取）；`ClasspathSkillRepository` 对应 classpath 扫描。
- 辅助：`util/SkillUtil` 提供从字符串/Zip 流构造 AgentSkill 的工厂；`MarkdownSkillParser` 解析 YAML frontmatter；`SkillFileSystemHelper` 封装目录遍历、读写与临时目录清理。
依赖方向：middleware → SkillBox → (registry, prompt provider, tool factory) → repository/util；SkillBox 反向持有 Toolkit 引用以同步 tool group 启用状态。
