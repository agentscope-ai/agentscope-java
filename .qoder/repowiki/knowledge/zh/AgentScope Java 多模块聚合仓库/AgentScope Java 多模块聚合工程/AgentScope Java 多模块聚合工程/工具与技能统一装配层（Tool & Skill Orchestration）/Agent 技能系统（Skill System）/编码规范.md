- 所有面向用户的入口类（AgentSkill、SkillBox、SkillUtil）均标注 `@Deprecated(since="2.0.0")`，表明该包已被弃用但保留兼容。
- 对外 API 对 null 参数采用「立即抛出 IllegalArgumentException」的守卫风格，并在日志中记录关键操作（register/remove/activate）。
- 可插拔的数据源通过接口 `AgentSkillRepository` 解耦，具体实现（FileSystem/Classpath）仅在方法内委托 `SkillFileSystemHelper`，不直接散落 IO 逻辑。
- 运行时可变状态集中在 `SkillRegistry` 这一纯存储层，上层（SkillBox/DynamicSkillMiddleware）只做组合与编排，遵循「单一职责」边界。
- 安全校验贯穿路径处理：上传时检查 `targetPath.startsWith(skillDir)`，load 工具侧通过 `sanitizeRelativePath` 拒绝 `/`、`..`、`.` 等相对路径穿越。
