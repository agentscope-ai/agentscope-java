本目录是协议扩展层的聚合根，按协议维度拆分子模块并通过 Maven multi-module 统一构建：
- agentscope-extensions-a2a 拆为 client/server 两个子模块，分别通过 Java SPI（META-INF/services）注册 `ClientTransportProvider` 与 `TransportWrapperBuilder`，实现 A2A 协议的客户端与服务端；
- agentscope-extensions-agui 提供 AG-UI 适配器，将内部 Agent 抽象转换为 AG-UI 消息/工具/事件模型；
- agentscope-extensions-chat-completions-web 暴露 OpenAI 兼容的 chat/completions REST 接口与流式适配器；
- agentscope-extensions-agent-protocol 基于 Spring Boot AutoConfiguration 注册 MVC 控制器与任务存储。
所有子模块共享同一根包前缀（io.agentscope.core.* / io.agentscope.extensions.*），外部应用按需引入对应 starter 即可启用相应适配层，各协议之间互不依赖，仅共同面向 AgentScope 核心运行时。
