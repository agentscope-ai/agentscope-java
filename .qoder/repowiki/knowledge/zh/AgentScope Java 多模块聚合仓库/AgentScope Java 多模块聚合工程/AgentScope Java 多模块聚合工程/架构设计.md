顶层 pom.xml 作为 Maven aggregator，将以下子域统一编排：agentscope-core（Agent 运行时、消息/事件/工具/技能/状态/权限等核心包）、agentscope-dependencies-bom（集中锁定所有依赖版本）、agentscope-extensions（按能力域拆分的模型/存储/RAG/通道/调度/沙箱/协议适配等 SPI 扩展）、agentscope-examples（演示与脚手架）、agentscope-harness（集成测试夹具）与 docs 站点；各子模块通过共享的 agentscope-dependencies-bom 锁定依赖版本，并通过 `io.agentscope.core` 包下的公共接口（Model、Tool、Skill、Hook、Event 等）形成跨模块契约，扩展子模块仅依赖 core 暴露的抽象并通过 SPI/Spring Boot AutoConfiguration 向核心注册实现。当前正在推进 sandbox-kubernetes 从直接管理 K8s Pod 改造为基于 agent-sandbox CRD (SandboxClaim/SandboxWarmPool) + HTTP API 的模式，并将操作逻辑下沉到独立的 agentscope-sandbox-client SDK 中以对齐 Python SDK 的 k8s_agent_sandbox 接口。
