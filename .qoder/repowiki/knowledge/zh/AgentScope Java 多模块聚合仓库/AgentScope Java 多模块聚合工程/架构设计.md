顶层 pom.xml 作为 Maven aggregator，按功能域将子模块划分为：agentscope-core（Agent 编排、消息、工具、技能、状态、中断、权限、RAG、Hook/Middleware 管线等核心 API）、agentscope-extensions-model/*（各 LLM Provider 的 SPI 实现）、agentscope-extensions-*（记忆、存储、沙箱、调度、协议、Studio、训练等横向能力）、agentscope-spring-boot-starters/*（基于 Spring Boot 自动装配的 starter）、agentscope-examples/*（演示应用）、agentscope-harness（集成测试驱动）以及 agentscope-distribution / agentscope-dependencies-bom（发布产物与依赖版本 BOM）。跨模块协作契约集中在 core 包中定义的接口与 SPI（如 Model、Tool、Skill、Hook、Middleware、PermissionEngine、StateStore 等），extension 与 starter 通过实现这些接口或声明式配置注入到 core 运行时；distribution 聚合所有模块并生成全量 jar，BOM 统一锁定第三方依赖版本，保证 core 与 extension 之间版本一致。当前正在推进 sandbox-kubernetes 向 agent-sandbox CRD + HTTP API 模式迁移，并将操作逻辑下沉为独立的 agentscope-sandbox-client SDK 模块。
