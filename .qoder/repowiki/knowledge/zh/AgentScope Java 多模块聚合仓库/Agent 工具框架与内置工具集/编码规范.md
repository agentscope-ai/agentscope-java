- 工具类优先继承 `ToolBase` 并使用其 Builder 构造，通过 `readOnly`/`concurrencySafe`/`externalTool`/`stateInjected`/`mcp` 等布尔字段声明安全语义，而非在 `callAsync` 中自行判断。
- 对 I/O 或系统调用的工具（Shell、文件读写）必须覆盖 `checkPermissions` 返回细粒度的 `PermissionDecision`，并在 `generateSuggestions` 中给出可被引擎采纳的 `PermissionRule`。
- 所有工具返回值统一为 `Mono<ToolResultBlock>`，错误通过 `ToolResultBlock.error(...)` 表达，外部工具通过抛出 `ToolSuspendException` 交由上层转换为 `TOOL_SUSPENDED` 消息。
- 需要跨平台行为的工具采用策略接口（如 `CommandValidator`）+ 工厂方法根据 `os.name` 选择具体实现，保持主逻辑与平台细节解耦。
- 面向用户的公开 API 使用 Builder/Fluent 风格（`ToolRegistration`、`ToolBase.Builder`、`SubAgentConfig.builder()`），内部构造器则保持最小参数集合。
