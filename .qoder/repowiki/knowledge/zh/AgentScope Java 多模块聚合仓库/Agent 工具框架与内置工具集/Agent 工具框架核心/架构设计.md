本模块按「抽象 → 通用实现 → 领域工具包」三层组织：
- 抽象层（`Tool`/`ToolBase`/`ToolGroup`/`Toolkit`/`ToolSchemaProvider`）定义工具元数据、分组与 Schema 暴露契约；
- 通用实现层（`ReflectiveFunctionTool`、`DefaultContextStore`、`DefaultToolResultConverter`、`MetaToolFactory` + `@Tool` 注解扫描、`ToolRegistry`、`ToolExecutor`）完成方法到工具的反射绑定、注册表维护与执行管线编排；`ToolValidator` 链与 `ToolEmitter` 在 `ToolExecutor` 中串联，形成统一的调用入口；
- 领域工具包（`builtin`、`file`、`coding`、`mcp`、`subagent`）仅依赖上述接口，不反向耦合，分别封装文件读写、Shell 命令、MCP 客户端与子代理能力。

跨子包协作要点：
- `MetaToolFactory` 通过 Jackson 的 `ToolSchemaModule` 生成 JSON Schema，供所有工具共享；
- `McpClientManager` 集中管理 MCP 客户端生命周期，被 `mcp/` 下各 Wrapper 复用；
- `SubAgentProvider` 作为 SPI 由 `subagent/SubAgentTool` 消费，使子代理可插拔；
- 安全边界由顶层 `ToolDangerousPathConstants` 与 `coding/CommandValidator`（含 Unix/Windows 双实现）在工具层拦截危险路径与系统命令，避免底层直接暴露 OS 能力。
