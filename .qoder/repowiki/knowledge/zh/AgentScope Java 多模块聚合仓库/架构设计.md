顶层 pom.xml 作为 Maven aggregator + BOM，通过 `<modules>` 声明所有子模块并集中管理依赖版本；`agentscope-core` 提供 ReActAgent 运行时与 agent/tool/skill/memory/hook/middleware 等核心接口，`agentscope-extensions` 下按能力域（model、memory、storage、sandbox、channel、rag、protocol、spring-boot-starter 等）拆分为独立子模块，均通过 Java SPI 向 core 暴露实现；`agentscope-distribution` 提供 all/bom 打包产物；`agentscope-examples` 与 `agentscope-harness` 消费 core+extensions 演示与集成测试；`docs` 使用 Sphinx 生成 v1/v2 双语文档。当前正在推进的跨模块重构：将 `agentscope-extensions-sandbox-kubernetes` 从直接操作 K8s Pod 改为通过独立的 `agentscope-sandbox-client` SDK 调用 agent-sandbox CRD (SandboxClaim/SandboxWarmPool) HTTP API，使 sandbox 客户端逻辑与具体部署后端解耦。
