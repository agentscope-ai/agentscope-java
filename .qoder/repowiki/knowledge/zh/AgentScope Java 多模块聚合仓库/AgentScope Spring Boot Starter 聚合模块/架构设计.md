Maven 多模块聚合器（packaging=pom），子 starter 之间无运行时依赖，各自独立注册 META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports；应用只需引入对应 starter，Spring Boot 自动装配即生效。
- 核心基础：agentscope-spring-boot-starter 暴露 Model/Memory/Toolkit/ReActAgent 默认 Bean，其他模型 starter（openai/dashscope/gemini/anthropic/ollama）通过 ChatModelBuilderCustomizer + @AutoConfiguration(before = AgentscopeAutoConfiguration) 在条件满足时覆盖默认实现。
- 横向扩展点：admin/a2a/agui/chat-completions/nacos 等 starter 均遵循「properties + AutoConfiguration + (controller/endpoint) + test」的统一结构，彼此可组合使用（如 admin + nacos 同时启用）。
- 启动期编排由 Spring Boot 的 @AutoConfiguration 机制完成，starter 间不互相 import，仅通过共享的 io.agentscope.* 包名约定与 YAML 前缀（agent.scope.* / agentscope.*）形成松耦合契约。
