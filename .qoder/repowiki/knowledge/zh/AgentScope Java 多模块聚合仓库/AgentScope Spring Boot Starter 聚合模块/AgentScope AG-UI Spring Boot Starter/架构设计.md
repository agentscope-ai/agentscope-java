本 starter 以 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 为统一入口，按运行时条件装配三个自动配置类：
- `AguiAgentRegistryAutoConfiguration`（common 包）：绑定 `AguiProperties`、创建线程安全的 `ThreadSessionManager`、生成 `AguiAgentId` 并通过 `AguiAgentRegistryCustomizer` 扫描 `@AguiAgent` 完成 Agent 自动注册；这是 MVC 与 WebFlux 共享的唯一业务中心。
- `AgentscopeAguiMvcAutoConfiguration`（mvc 包）：在 Servlet 环境下注册 `AguiRestController`，将 `/agui/**` 映射到注册表。
- `AgentscopeAguiWebFluxAutoConfiguration`（webflux 包）：在响应式环境下注册 `AguiWebFluxHandler`，复用同一注册表。
MVC 与 WebFlux 两个子包各自使用 `@ConditionalOnClass` 仅当对应 starter 在 classpath 时才生效，从而让单一 starter 同时兼容传统 Servlet 与响应式应用，请求处理层与 Agent 发现/路由逻辑完全解耦。
