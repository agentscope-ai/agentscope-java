- 所有持久化组件均接收外部注入的 `javax.sql.DataSource`，不持有连接池生命周期，自身只负责 JDBC 调用并在构造器中校验非空。
- 构造器或 Builder 中统一通过正则表达式严格限定 schema/table/key 等标识符，防止 SQL 注入。
- SQL 常量集中声明为 `static final String`，在构造函数中以 `String.format` 注入表名后缓存到实例字段，避免运行时重复拼接。
- 可选的 DDL 初始化统一通过 `initializeSchema(true)` / `createIfNotExist(true)` 开关控制，生产环境默认关闭，交由迁移工具管理。
- 异常包装遵循“业务语义 + 原始 SQLException”模式，统一抛出 `IllegalStateException` / `RuntimeException` 并在消息中包含失败的操作名称。
