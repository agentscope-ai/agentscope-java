本目录是 AgentScope Core 的扩展聚合仓库，所有子模块遵循统一的编排契约：
- 每个能力域（model、mem、channel、rag、scheduler、sandbox、storage、protocol、studio、training、nacos、higress、cos/oss/mysql/redis 等）对应一个独立 Maven 子模块，彼此无运行时依赖，仅通过 AgentScope Core 提供的接口或 SPI 反向被发现。
- 模型与协议类扩展通过 `resources/META-INF/services/` 注册 Provider（如 ModelProvider），Spring Boot 相关 starter 则通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 完成自动装配，使应用无需显式配置即可启用扩展。
- 存储/分布式能力（mysql、redis、cos、oss）统一以 `*DistributedStore` + `*AgentStateStore` + `*RemoteSnapshotClient` + `*SnapshotSpec` 四件套形式提供，由上层根据配置选择具体实现。
- Spring Boot Starter 层（agentscope-spring-boot-starters/*）为各扩展提供 `@EnableXxx` 与 `application.yml` 属性绑定，屏蔽底层客户端差异。
- 跨子模块共享的基础构件（如 channel-common 中的 BotLoopGuard/IdempotencyStore、scheduler-common 中的 AgentScheduler 抽象）由父 POM 管理版本，避免重复实现。
