Maven 子模块，仅依赖 `agentscope-harness`（provided），对外暴露聚合入口类 `PostgresDistributedStore`，通过 `create(DataSource)` 工厂方法一次性装配四个独立的后端：
- `state/PostgresAgentStateStore`：实现 `io.agentscope.core.state.AgentStateStore`，使用 schema `agentscope` + 表 `agentscope_sessions`，单值存于 `item_index=0`，列表按行拆分并通过 `ListHashUtil` 做增量写入；支持 Builder 自定义 schema/table 名与自动建表。
- `store/PostgresBaseStore`：实现 `BaseStore`，使用表 `agentscope_store`，以 ASCII Unit Separator (0x1F) 拼接 namespace 并用 `LIKE ... ESCAPE '!'` 模拟前缀搜索；CAS 通过 `version` 列的单语句 UPDATE 实现，多 JVM 共享数据库时无额外锁。
- `snapshot/PostgresRemoteSnapshotClient` + `PostgresSnapshotSpec`：将沙箱 tar 包以 BYTEA 存入 `agentscope_snapshots` 表，由 `PostgresSnapshotSpec` 作为 `SandboxSnapshotSpec` 暴露给 Harness。
- `sandbox/PostgresSandboxExecutionGuard`：基于 `pg_advisory_lock(key)` / `pg_try_advisory_lock` 实现跨进程互斥，key 由 `MurmurHash3` 对 `scope:value` 计算得到，默认超时 30 分钟，连接关闭时自动释放。

依赖方向单向指向 `io.agentscope.harness.*` 接口，模块内部各子包之间无相互引用，仅由顶层 `PostgresDistributedStore` 组合装配。
