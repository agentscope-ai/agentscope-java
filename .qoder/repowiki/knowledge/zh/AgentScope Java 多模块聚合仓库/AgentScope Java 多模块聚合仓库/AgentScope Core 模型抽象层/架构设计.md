本模块由三个并列子包构成同一抽象层的不同切面：
- `model/` 定义顶层 `Model` 接口及 `ChatModelBase` 基类，并通过 `transport/` 子包将 HTTP/WebSocket 传输细节与模型调用解耦；`spi/ModelProvider` 和 `ModelRegistry` 负责按名称发现并构造具体模型实例。
- `credential/` 提供各厂商的 `*Credential` 类型（DeepSeek、Kimi、XAI 等），它们通过 JSON 序列化被 `ModelCard` 消费，供 `ModelProvider` 在注册时注入认证信息。
- `formatter/` 暴露 `Formatter` 接口与 `AbstractBaseFormatter` 基类，用于在模型请求/响应与 Agent 内部消息格式之间做双向转换。
三者共同受 `Model` 接口约束：`ModelProvider` 用 `Credential` 构造 `Model`，`Model` 内部通过 `Transport` 发送经 `Formatter` 编码的请求，从而形成「凭据 → 模型 → 传输 → 格式化」的单向依赖链，屏蔽下游厂商差异。
