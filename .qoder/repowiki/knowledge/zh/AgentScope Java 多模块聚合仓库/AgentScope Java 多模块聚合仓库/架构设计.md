顶层 pom.xml 作为 Maven aggregator，通过 `<modules>` 声明子模块并按依赖顺序构建；`agentscope-core` 定义所有公共 SPI（如 `Model`、`Memory`、`Tool`、`AgentSkillRepository`、`Sandbox`、`Channel`、`StateStore` 等接口），各 `agentscope-extensions-*` 子模块仅依赖 core 并实现对应 SPI，形成「核心契约 + 插件化实现」的解耦结构。

- 启动装配：`agentscope-extensions-spring-boot-starters/*` 中的 Spring Boot AutoConfiguration 通过 `@ConditionalOnClass` 扫描并注册具体实现到 `ModelRegistry`、`SkillRegistry`、`LongTermMemory` 等全局注册表，使运行时按 classpath 自动装配。
- 事件总线：`agent/event` 下的 `AgentEventEmitter` 与 `hook` 下的 `Hook` 是贯穿 agent 执行链的统一横切点，被 ReActAgent、中间件、Studio 集成、训练采集等多个子模块消费。
- 传输抽象：`model/transport` 提供 HTTP/WebSocket 传输 SPI，DashScope/Gemini/Ollama/OpenAI 等模型适配器复用同一套 transport 层，避免重复网络栈。
- 分发产物：`agentscope-distribution` 通过 `agentscope-all` 打包全量依赖供 CLI 使用，`agentscope-bom` 统一版本管理，确保 core、extensions、starters 三方版本一致。
