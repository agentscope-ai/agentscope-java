- 每个扩展能力在 agentscope-core 中定义 SPI 接口，具体实现放在独立的 agentscope-extensions-* 模块并通过 Spring Boot AutoConfiguration 注册到全局 Registry。
- 模型适配器统一继承 ChatModelBase 或 Model 接口，并通过 model/transport 层的 HTTP/WebSocket 抽象发起请求，禁止直接引入第三方 SDK。
- 可插拔组件（Memory、Tool、SkillRepository、Sandbox、Channel）均采用「接口 + 默认实现 + 扩展实现」三层结构，并通过 @Component 暴露给容器发现。
- 事件驱动扩展统一基于 agent/event 包下的 AgentEventEmitter 发布事件，hook 扩展基于 hook/Hook 接口拦截生命周期。
