- 所有对外异常最终归一为 `OpenAIException` 或其子类，并通过静态工厂 `OpenAIException.create(statusCode, message, errorCode, body)` 构造，再在 Model 层包装为 `ModelException` 向上抛出。
- HTTP 层对 base URL 做版本段裁剪：当 basePath 匹配 `.*\/v\d+$` 时从 endpoint 中去除前导 `/v1`，避免重复拼接版本号。
- Formatter 采用模板方法模式：`OpenAIBaseFormatter` 提供 `parseResponse`、`applyCacheControl`、`buildRequest` 等公共逻辑，各提供商子类仅覆写 `doFormat`、`applyOptions`、`applyTools`、`applyToolChoice` 四个抽象方法。
- Builder 模式用于 `OpenAIChatModel.Builder`，默认值集中设置（如 `stream=true`），并在 `build()` 中通过 `GenerateOptions.mergeOptions` 与 `ModelUtils.ensureDefaultExecutionConfig` 完成最终合并。
- DTO 全部为无行为 POJO，字段直接映射 OpenAI JSON 结构，序列化/反序列化统一走 `JsonUtils.getJsonCodec()`，不在 DTO 内编写解析逻辑。
