顶层 `agentscope-extensions-model` 仅作为 Maven 聚合器（pom packaging），不包含任何业务代码；各 provider 子模块彼此零依赖，仅共同依赖 `agentscope-core` 的 model SPI 接口，通过 `META-INF/services/io.agentscope.core.model.spi.ModelProvider` 注册各自的 `*ModelProvider` 实现，由运行时自动发现并注入。每个 provider 严格遵循同一分层契约：`credential/*` 封装鉴权、`dto/*` 映射厂商 JSON、`formatter/*` 承担 AgentScope 内部消息与厂商协议的双向转换（ChatFormatter/MessageConverter/MediaConverter/MultiAgentFormatter/ResponseParser/ToolsHelper）、顶层 `*ChatModel` 调用 HTTP SDK 并驱动流式/阻塞两种模式。`agentscope-extensions-model-e2e-tests` 独立于所有 provider，通过 `providers/*Provider` 抽象工厂对同一组 ReAct Agent 场景进行跨提供商回归验证，上层应用按需引入具体 provider 依赖即可。
