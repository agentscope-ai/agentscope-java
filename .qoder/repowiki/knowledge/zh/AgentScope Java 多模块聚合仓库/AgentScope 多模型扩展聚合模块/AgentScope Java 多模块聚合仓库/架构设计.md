顶层 pom.xml 作为 Maven aggregator，通过 `<modules>` 声明所有子模块并按依赖顺序组织：`agentscope-core` 提供 agent、tool、message、model、hook、middleware、state、skill、permission、tracing、shutdown 等核心包；`agentscope-extensions-model` 下的各厂商实现（OpenAI/DashScope/Gemini/Ollama/Anthropic）通过 Java SPI 注册到 core 的 `ModelRegistry`；`agentscope-extensions-*` 按能力域（channel/cos/mem/mysql/postgresql/redis/oss/sandbox/scheduler/rag/nacos/studio/training/a2a/agui/chat-completions-web）拆分为独立 jar，统一由 `agentscope-spring-boot-starters` 中的 AutoConfiguration 自动装配；`agentscope-distribution` 提供 `agentscope-all` fat jar 和 BOM；`agentscope-examples` 与 `agentscope-harness` 消费 core + extensions 进行集成验证；`docs/` 使用 Sphinx 生成 v1/v2 双语站点。跨模块契约集中在 core 的 `io.agentscope.core.model.spi`、`io.agentscope.core.tool.Tool`、`io.agentscope.core.hook.Hook`、`io.agentscope.core.skill.Skill` 等接口上，extension 仅依赖这些抽象而不反向依赖 core 的具体实现。
