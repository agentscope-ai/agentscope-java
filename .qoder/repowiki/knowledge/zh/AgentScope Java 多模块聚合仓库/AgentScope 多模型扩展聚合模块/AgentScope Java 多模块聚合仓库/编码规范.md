- Extension 模块通过 `META-INF/services/java.util.ServiceLoader.Provider` 或 `@AutoService` 向 core 暴露实现，禁止在 extension 中直接 import core 具体类
- 每个扩展能力域（model/channel/storage/sandbox/...）拆为独立 Maven 子模块，并通过独立的 spring-boot-starter 暴露 `spring.factories` / `AutoConfiguration`
- 所有对外 API 以接口形式定义在 core，实现类放在对应 extension 模块，遵循面向接口编程的单向依赖原则
