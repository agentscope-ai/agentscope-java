顶层 pom.xml 作为 Maven aggregator，按单向依赖树组织子模块：agentscope-core 提供 Agent/Model/Memory/Tool 等核心接口；agentscope-extensions 下的各 *-extension-* 模块通过 SPI 或 Spring Boot AutoConfiguration 向 core 暴露实现（模型、存储、RAG、沙箱、调度、通道等），不反向依赖 core 源码；agentscope-distribution 通过 agentscope-bom 锁定所有子模块的公共依赖版本，并通过 agentscope-all 生成 shaded jar；agentscope-examples 与 agentscope-harness 仅消费已发布的坐标，不参与核心链路；docs 使用 Jupyter Book 独立构建。该结构使 core 成为唯一稳定契约面，extensions 以插件形式热插拔，distribution 负责对外发布的一致性。
