模块以 `HarnessAgent`（实现 `Agent`）为唯一对外入口，内部委托一个 `ReActAgent` 实例，并在其构建阶段按固定顺序注入中间件：`SandboxLifecycleMiddleware` → `AgentTraceMiddleware` → `WorkspaceContextMiddleware` → `AtPathExpansionMiddleware` → `MemoryFlushMiddleware` → `MemoryMaintenanceMiddleware` → `CompactionMiddleware` → `ToolResultEvictionMiddleware` → `InboxMiddleware` → (`DynamicSubagentsMiddleware` | `SubagentsMiddleware`) → `AsyncToolMiddleware` → `PlanModeMiddleware` → `SkillCurator/SkillUsage` 中间件。每个中间件通过 `IsolationScope` 与 `SandboxContext` 共享隔离边界。

子系统分层（依赖方向自上而下）：
- `gateway/*`：基于 `Channel`/`ChannelRouter` 的消息网关，负责会话路由、子代理注册与唤醒分发；`HarnessGateway` 作为内部网关由 `HarnessAgent` 懒创建。
- `filesystem/*`：统一 `AbstractFilesystem` 接口，支持 local/sandbox/remote/composite/overlay/baked 等多种后端，通过 `*Spec` + 工厂模式解耦实现。
- `sandbox/*`：`SandboxManager` 统一管理生命周期，默认 Docker 实现位于 `impl/docker`，快照/布局/挂载分别由 `snapshot/`、`layout/`、`WorkspaceProjectionApplier` 抽象。
- `memory/*`：会话树 + 压缩/刷新策略，被 `MemoryFlushMiddleware` 与 `CompactionMiddleware` 消费。
- `skill/*`：`SkillCurator`（过滤/安全扫描/审计/推广）+ `SkillRuntime`（加载/缓存），暴露 `SkillManageTool` 供 Agent 动态加载。
- `subagent/*`：声明式子代理与任务仓库（`TaskRepository`/`WorkspaceTaskRepository`），配合 `task`/`task_output` 工具异步执行。
- `workspace/*`：工作区索引（SQLite）、路径规范化与 Plan Mode 管理。
- `bus/*`：基于文件系统的消息总线与异步工具注册表，支撑 Inbox 与异步工具回调。

所有组件通过 Maven 单模块发布，测试复用 `agentscope-core:test-jar` 中的 MockModel/MockToolkit。
