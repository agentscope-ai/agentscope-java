- 每个文档页使用 MyST frontmatter 中的 `title:` 字段定义页面标题，并依赖 `myst_title_to_header` 自动提升为 H1，避免触发 Sphinx 缺少标题警告。
- 跨语言内容采用 `vN/{en,zh}/...` 镜像目录结构，同一功能在 en/zh 下保持相同相对路径，便于 `_toc.yml` 与 JS 路由逻辑统一处理。
- 顶栏 Tab 与侧边栏章节在 `_toc.yml` 的 `sections_*` 与 `_config.yml` 的 `docs_top_tabs[].prefixes_*` 中成对维护，确保 tabs.js 能根据当前 URL 前缀匹配正确的版本与语言路由。
- 公告条通过 `_config.yml` 的 `html_context.docs_site_notice` 字典集中开关与文案，并通过递增 `id` 字段控制用户已关闭状态的失效。
