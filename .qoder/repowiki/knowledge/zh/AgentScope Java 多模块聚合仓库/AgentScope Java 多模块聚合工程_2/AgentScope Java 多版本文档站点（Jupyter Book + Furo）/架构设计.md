纯静态文档工程，以 `pyproject.toml` 作为 setuptools shim 暴露 jupyter-book/sphinx 工具链，无 Python 包产出。
- 内容层：`v1/` 与 `v2/` 下各自按 `en/`、`zh/` 镜像组织 Markdown 源文件；根 `_toc.yml` 通过 `parts/chapters/file` 显式声明两个版本的导航树，并以 `root: v2/en/intro` 指向最新版入口。
- 配置层：`_config.yml` 中 `html_baseurl=https://java.agentscope.io/` 配合 `docs_version`/`docs_versions` 实现 `/v1/` 与 `/v2/` 的路由分发；`html_context.docs_top_tabs` 为每个顶栏 Tab 维护 `href_*`/`prefixes_*`/`sections_*` 四套路由前缀，供前端 JS 根据当前 URL 选择对应版本与语言。
- 主题与模板层：使用 Furo 主题，通过 `templates_path: ["./_templates"]` 注入 `page.html`、`top-tabs.html`、`version-switcher.html`、`language-switch.html`、`docs-site-header.html`、`docs-site-notice.html` 等 Jinja 模板，覆盖侧边栏、顶栏 Tabs、语言/版本切换器以及全局公告条。
- 静态资源层：`_static/` 下的 `tabs.js`、`language.js`、`version.js`、`notice-bar.js`、`mermaid-zoom.js`、`ai-context-menu.js` 在运行时根据 URL 前缀 (`v1`/`v2`) 和浏览器语言选择对应路由；`_extra/imgs` 通过 `html_extra_path` 映射到站点根路径，供原始 HTML 引用。
- 扩展层：`_sphinx_extensions/root_index_notice.py` 作为 `local_extensions` 注册的本地 Sphinx 扩展，修补根 `index.html` 使公告条在 `/` 上生效；`scripts/convert_v2_mdx.py`、`scripts/generate_v1_redirects.py` 提供从 Mintlify MDX 迁移与旧版重定向生成的辅助脚本。
- 依赖方向：内容 → `_toc.yml`/`_config.yml` → Sphinx/Furo 渲染 → 输出静态站点；JS/CSS 仅被模板引用，不反向依赖内容。
