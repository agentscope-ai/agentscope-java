# JEV 内部参考资料

本目录不进入文档站点。面向用户的唯一文档入口是 `docs/v2/zh/jev/index.md`。

`archive-2026-09-26/` 保留重组前的调研、设计、阶段规划、验收日志、模型对照原始记录和发布快照。内容是历史材料，可能与当前代码不一致；后续开发应先核对实现，不把历史计划当作当前能力。

- `research-and-development`：原 `docs/jev`。
- `published-zh-before-reorganization`：原正式中文页面。
- `published-en-before-reorganization.md`：原英文页面。
- `published-downloads`：历史测试、源码下载和证据附件。

后续设计讨论、进度、参考项目映射和开发验证记录放在本目录，用户文档只保留功能、场景、API、运行方法及行为边界。

## 用户文档写法

功能页先用一段话说明能力，再展开一个具体场景：用户请求、已有工具或输入、容易出错的行为、JEV 在哪一步解决什么问题。紧跟同一场景展示 API，逐项解释配置如何影响这个场景，再展示 Agent 接入和结果。模式对比仍使用同一场景。异常、权限与高级边界放在后面，不让读者先阅读大量底层契约。参考当前 `tool-guard-api.md`，代码片段应验证与实际 API 一致。
