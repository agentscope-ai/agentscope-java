# Nested aistio layout

This directory is the Go control plane used by `agentscope-service` (`dev-up.sh`).

Do **not** IDEA-copy / Undo-copy this tree into the Java monorepo again.
It has its own `.git` so changes can be committed here independently of
`agentscope-java`. Prefer pushing to the aistio remote or converting to a
git submodule when ready.
